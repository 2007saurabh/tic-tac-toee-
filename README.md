# ⭕ Tic-Tac-Toe · Advanced Edition

A modern, feature-rich Tic-Tac-Toe game built with vanilla HTML, CSS, and JavaScript.

## ✨ Features
- 🤖 AI opponent (4 difficulty levels)
- 👥 2-player mode
- ↩️ Undo / Redo
- 🔊 Sound effects
- ⏱️ Move timer
- ⌨️ Keyboard navigation
- 📱 PWA-ready (installable)
- 💾 Persistent scores

## 🎮 Play Online
👉 [Play the game](https://2007saurabh.github.io/tic-tac-toee-/)

## 🚀 Run Locally
1. Clone the repo: `git clone https://github.com/2007saurabh/tic-tac-toe.git`
2. Open `index.html` in your browser.

## 🛠️ Tech Stack
- HTML5
- CSS3 (Grid, Flexbox, Animations)
- Vanilla JavaScript (ES6+, Minimax AI)
- Web Audio API
- Service Worker + Manifest (PWA)
